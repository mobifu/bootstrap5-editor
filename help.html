Erste Schritte

Was ist der Bootstrap 5 Low-Code Editor?

Mit dieser Software können Sie moderne Webseiten wie mit einem Baukastensystem zusammenstellen. Sie müssen keinen einzigen HTML-Code schreiben! Der Editor erledigt die gesamte technische Arbeit für Sie im Hintergrund.

In 3 einfachen Schritten zur eigenen Webseite:
1
Elemente hinzufügen

Klicken Sie in der linken Werkzeugleiste auf ein Element (z. B. Überschrift, Text, Bild oder Button).

2
Inhalte anpassen

Geben Sie Ihren gewünschten Text ein, wählen Sie Farben oder fügen Sie Links ein.

3
Vorschau & Export

Betrachten Sie Ihre fertige Seite direkt im Webbrowser oder exportieren Sie den HTML-Code.

Die Benutzeroberfläche

1. Werkzeuge (Links)

Hier finden Sie alle Buttons zum Erstellen neuer Bausteine, zum Laden/Speichern von Projekten und den Bootstrap-Konverter.

2. Seitenstruktur (Mitte)

Zeigt den Aufbau Ihrer Webseite an. Hier sehen Sie alle Zeilen, Spalten und Elemente, können deren Reihenfolge ändern oder Inhalte bearbeiten.

3. Vorschau & Code (Rechts)

Hier wird der erzeugte Code live angezeigt. Über die oberen Buttons können Sie die Webseite direkt im Browser öffnen.

Verfügbare Elemente & Funktionen

Hier ist eine Übersicht aller Bausteine, die Sie in Ihre Spalten einfügen können:

Überschrift & Text
Überschriften & Textblöcke

Fügen Sie große Titel (H1 bis H6) oder normale Textabsätze hinzu. Sie können den Text jederzeit wieder ändern.

Medien
Bilder

Fügen Sie Bilder per Web-Adresse (URL) oder von Ihrer Festplatte ein. Lokale Bilder werden automatisch optimiert.

Interaktion
Schaltflächen (Buttons)

Erstellen Sie klickbare Knöpfe mit Ziel-Link und Farbstil (z. B. Blau für Primär, Grün für Erfolg).

Hinweis
Hinweisboxen (Alerts)

Hervorgehobene Infoboxen für wichtige Nachrichten, Warnungen oder Erfolgsmeldungen.

Layout
Karten (Cards)

Ein umrahmter Kasten mit Titel und Inhalt – ideal für Produktpräsentationen oder Dienstleistungen.

Struktur
Akkordeon (Einklappbereich)

Mehrere Bereiche, die per Klick auf- und zuklappen. Perfekt für FAQ-Bereiche.

Daten
Tabellen & Listen

Strukturierte Aufzählungen oder Tabellen mit Zeilen und Spalten für übersichtliche Daten.

Experten
Eigener HTML Code

Für fortgeschrittene Nutzer: Fügen Sie benutzerdefinierten HTML-Code direkt ein.

Formulare
Formularfelder (Input & Textarea)

Ermöglicht Eingabefelder für E-Mail, Text, Passwort und mehrzeiligen Text (Textarea) inklusive Beschriftungen.

Navigation
Navigationsleiste (Navbar)

Responsive Bootstrap Headerleiste mit Shop-/Website-Namen (Brand) und frei konfigurierbaren Navigationslinks.

Interaktion
Modalfenster (Popups)

Öffnet beim Klick auf eine Schaltfläche ein Pop-up-Dialogfenster mit individuellem Titel, Beschreibungstext und Schließen-Button.

Abstände anpassen (Margin & Padding)

Für jedes Element können Sie ganz einfach die Abstände nach oben und unten festlegen, damit Ihre Webseite aufgeräumt wirkt:

  • Außenabstand (Margin): Schafft Platz außerhalb des Elements zu den Nachbarelementen.
  • Innenabstand (Padding): Schafft Platz innerhalb des Elements (z. B. Abstand vom Text zum Rand einer Karte).
Tipp: Wählen Sie beim Anpassen einfach Werte von 0 (kein Abstand) bis 5 (großer Abstand).

Bootstrap 3 ➔ Bootstrap 5 Konverter

Älteren Webseiten-Code automatisch aktualisieren

Haben Sie alten HTML-Code von einer früher gebauten Bootstrap 3 Webseite? Nutzen Sie den integrierten Konverter:

  1. Klicken Sie in der linken Leiste auf den lila Button "BS3 ➔ BS5 Konverter".
  2. Fügen Sie Ihren alten Code in das obere Textfeld ein.
  3. Klicken Sie auf "Konvertieren".
  4. Der Editor passt veraltete Befehle automatisch an die moderne Bootstrap 5 Version an!

Projekte Speichern & Laden

Damit Ihre Arbeit nicht verloren geht, können Sie Ihr aktuelles Projekt jederzeit abspeichern:

  • Projekt Speichern: Speichert Ihren gesamten Seitenaufbau in einer Projektdatei auf Ihrem Computer ab.
  • Projekt Laden: Öffnet ein zuvor gespeichertes Projekt, sodass Sie direkt weiterarbeiten können.

Vorschau & HTML Export

Ihre fertige Webseite nutzen

Wenn Ihre Seite fertig ist, haben Sie drei Möglichkeiten:

Vorschau im Browser

Öffnet die Webseite sofort in Ihrem Standard-Webbrowser zur Kontrolle.

HTML Exportieren

Speichert die fertige HTML-Datei ab, um sie z.B. ins Internet hochzuladen.

Code Kopieren

Kopiert den gesamten HTML-Code direkt in Ihre Zwischenablage.
